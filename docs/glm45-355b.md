# 单台 DGX Spark：GLM-4.5 355B 固定长度推理

对 UD-IQ1_S 两个权重分片（97,047,546,752 字节）逐片核验 SHA-256。固定 llama.cpp 后端报告 94/94 层放在 GPU（含输出层）；这里按后端日志口径计数，不代表每个文件张量都用于解码。
加载器明确跳过了第 92 号块（NextN）的全部 25 个张量。逐名核对 GGUF 目录和原生日志，匹配 1,841,313,408 个压缩字节、5,539,962,272 个存储元素；本次没有运行这个预测块。主模型是 GLM-4.5，不能据此声称运行了 MTP。
复跑时可从本地 `server.private.log` 提取 `model has unused tensor … -- ignoring` 记录。按张量名排序，将每行写为 `名称<TAB>十进制字节数<LF>`（无表头），SHA-256 应为 `3ef32ce91379a58c0c9f8327535c771cc925e93becba5ed168371385bfaf39d4`。

| 输入 token | 预填充中位（秒） | 解码中位（秒） | 本机 HTTP 中位（秒） | 正逆序输出相同 |
|---:|---:|---:|---:|---:|
| 128 | 1.220 | 1.356 | 2.588 | 2/2 |
| 1024 | 8.395 | 1.399 | 9.809 | 2/2 |

装载/请求阶段观测到的系统最低 MemAvailable 分别为 26.71 / 26.63 GiB。它们是每秒采样的系统值，不是模型显存峰值。

每个长度两个不同提示，正逆顺序各一次；模型已加载，每次从冷提示开始，屏蔽终止符，固定生成 16 个 token。这不估计通用回答质量、长上下文能力或生产吞吐。

```bash
B=benchmarks/quant_serving; R=reports/glm45-355b
python3 -E -B -S "$B/audit_glm355.py" audit "$B/glm45-udiq1s.lock.json" "$R" | cmp - "$R/summary.json"
```

### 独立复核输入 token

无需 GPU 或权重即可比对已发布请求的四组输入 ID 和后端终止符。这里核对的是喂给模型的输入，不是对输出质量评分。

```bash
python3 -E -B -S "$B/glm_token_contract.py" compare "$R/tokenizer-contract.json" "$R/rows.json" "$R/runtime.json"
```

如需重新生成独立参考，设置 `LLAMA_SRC` 为固定提交的 llama.cpp 源码目录、`LLAMA_BIN` 为包含已核验 libllama 的绝对目录、`FIRST_SHARD` 为锁定的第一个 GGUF 分片。只读取分片开头 16 MiB；原生分词器不会加载权重，也不创建推理上下文。

```bash
(
  set -eu; T=$(mktemp -d); trap 'rm -f -- "$T/header" "$T/tokenizer" "$T/contract.json"; rmdir -- "$T"' EXIT
  head -c 16777216 "$FIRST_SHARD" > "$T/header"
  c++ -O2 -std=c++17 -I"$LLAMA_SRC/include" -I"$LLAMA_SRC/ggml/include" "$B/glm_tokenize_vocab.cpp" -L"$LLAMA_BIN" -Wl,-rpath-link,"$LLAMA_BIN" -lllama -ldl -o "$T/tokenizer"
  python3 -E -B -S "$B/glm_token_contract.py" preflight "$T/header" "$T/tokenizer" "$LLAMA_BIN/libllama.so" reports/qwen235b/runtime.json > "$T/contract.json"
  cmp "$T/contract.json" "$R/tokenizer-contract.json"
)
```

### 真机复跑

从仓库根目录运行。同一台空闲 DGX Spark，固定 llama.cpp 构建方式见[量化服务说明](../benchmarks/quant_serving/README.md)。先设置 `SERVER` 为该构建的 llama-server，`WEIGHTS` 为目标文件系统上的空目录。在下载前采样准入（退出 75 表示拒绝；不要继续）：

```bash
set -eu
B=benchmarks/quant_serving; W=$(mktemp -d); export TRANSFER_RECEIPT="$W/before-download.json"
python3 -B "$B/audit_glm355.py" transfer "$B/glm45-udiq1s.lock.json" "$WEIGHTS" --budget "$B/glm45-budget.json" > "$TRANSFER_RECEIPT"
```

随后才从锁定的模型版本下载 `UD-IQ1_S` 目录中的两个指定分片，保留原文件名，放在 `$WEIGHTS` 根目录。下列命令会再次检查可用内存、逐片读取并校验 SHA-256、核对张量目录，之后才启动仅监听本机的服务。不要用发布的准入文件冒充本机采样。

```bash
export SERVER WEIGHTS OUT="$W/run"
bash "$B/run_glm355.sh"
python3 -E -B -S "$B/audit_glm355.py" audit "$B/glm45-udiq1s.lock.json" "$OUT" | cmp - "$OUT/summary.json"
```

**English.** One GB10, pinned mixed-quantized GLM-4.5, four synthetic prompts repeated in reverse order. Raw rows and admissions can be replayed offline. CUDA inference uses upstream llama.cpp; these observations do not measure general quality.
