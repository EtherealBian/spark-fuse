# One rejected packed LayerNorm binary

An early `block/128/cache/vec4` CUDA binary (SM 12.1, nvcc 13.0.88, generated source in `before.cu`, original compile key `48d24bc95b713370948246fb5d918fc8ff3215c043535200e098295f080267d5`) issued an out-of-bounds read in the 768-wide two-output test after preceding shapes had run. A fresh process with just that input could pass; rerunning only the last shape was not a sufficient check. Compressed files retain the pre-fix full test and memcheck output. The first bad read is in the **generated fused kernel**, not eager.

For packed LayerNorm only, the generator now disables unrolling of the *outer packet traversal*. The inner 1/2/4/8-element packet remains specialized. The same full sequence of 24 cases passed under **unfiltered** Compute Sanitizer memcheck (`after-memcheck.txt`). This verifies the tested binary/shapes, not every possible driver/compiler/shape. Later mixed-affine/offset cases extend the suite. Reproduce from the repository root: `source tools/env.sh; flock .runtime/gpu-execution.lock compute-sanitizer --tool memcheck --error-exitcode 86 "$PY" -m pytest -q tests/test_layernorm.py`.

The broader discovery panel then exposed a *separate scalar case*: the initial outer-loop guard covered only packed loads. The BF16 `block/128/cache/vec1` cache key `70cc29e9d31ddc05e6bf272265306a3ef497bd31b4c4737e6bfc46fe8c5186da` failed in the generated scalar launch on the 1 × 768 discovery case; its source and memcheck trace are also retained. Both scalar and packed traversals now use the guard. `tools/layernorm_audit.py` enumerated **all 72 selectable layouts** for 14 × 768 BF16 with two independent inputs and different alignment offsets; unfiltered memcheck reported zero errors (`schedule-memcheck.txt`, per-schedule IDs and numerical errors in `../layernorm-schedules-gb10.json`). This is empirical coverage, not a general assertion about nvcc. Mixed-dtype affine parameters are rejected: CUDA eager in the tested environment itself rejected the FP32 weight/bias, low-precision input combination.
