# 235B: physical prefill tile size under natural termination
Freeze before any held-out inference. CUDA upstream llama.cpp; one GB10. This is not the existing 128/1024-input fixed 16-token study. Four fresh processes (microbatch 128/256/256/128), same verified 85.69 GB checkpoint, 512 logical batch, one slot, 4096 context. No conflicting GPU work. Refuse failed memory admission; whole-cgroup wall-clock fence.

## Input/output
Two never-before-measured 512/2048-token role-framed input pairs (extract a known label; explain a maintenance decision). Raw role delimiter IDs, tokenizer hash and sequence hashes frozen by a separate metadata-only CPU tokenizer. Each server's four token arrays must agree. Greedy, 48-token cap, actual EOG permitted, no explicit stop strings, no grammar, no EOG logit mask. Each launch records forward/reverse cold SSE order then four separate non-stream witnesses, excluded from latency. Compare both first non-whitespace text, first returned ID, and terminal latency. Timing includes the HTTP request; recorded events are client observations, not individual kernel times. Normalize only leading/trailing whitespace for literal label match and report it separately (no general quality score).

## What would qualify
For every held-out case and BOTH arm orders, median of the two paired first-visible latency savings >=5%, and terminal latency saving >= -3%. Controls must fully match the alternative on full witness IDs/text/stop, and every actual SSE delivery must completely match its own witness. Holes in the backend sample ordinal are reported, not filled; EOG and cap are counted separately. At least one case must actually reach natural EOG in all four blocks. A divergence is measured and retained, not a reason to discard a run. Invalid framing, wrong weights/runtime, memory guard failure, missing witnesses, missing/falsified timestamps, prompt oracle mismatch or partial run does not count. No general default change even if all gates pass. A witness is an independent greedy request, not access to hidden stream tokens.
